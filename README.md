# ゼミログ

オンラインのゼミや会議の音声を録音し、PCの中で日本語に文字起こししながら、話の要点をLLMにまとめさせるWindowsアプリです。

- 対象: Windows 11（WPF、.NET 10）
- 文字起こしはPCの中だけで行い、音声は外へ送りません。
- 要約には、OpenAI互換のAPIで動くLLMのサーバーを使います（自分で用意したローカルのQwenで確認）。

## なぜ作ったか

ゼミで研究への指摘や助言をもらうとき、メモを取りながら聞くと聞き漏らしが出て、メモに気を取られると話にも集中できませんでした。録音して後から聞き直すのは時間がかかります。

そこで、話している最中に文字起こしと要約が進み、終わった時点で「何を言われたか」がまとまっているアプリを作りました。ゼミの音声や発表資料をそのまま外部のサービスに送るのは避けたかったので、文字起こしはPCの中で行い、要約も自分で用意したサーバーに送る形にしています。

## できること

- マイク（自分の声）と相手の音を別々に録音します。相手の音は、PC全体で鳴っている音か、Zoom・Teams・ブラウザなど特定のアプリの音を選べます。
- 録りながら日本語に文字起こしし、録った経路で「自分」「相手」を分けて表示します。
- 約45秒ごとにそこまでの要点をまとめ、録音を止めると全体の要約を作ります。
- 発表資料（PPTX）を選ぶと、スライドの本文・番号・発表者ノートを要約の手がかりに使います。
- 過去の記録の一覧、自分と相手の音を混ぜた再生、Markdownへの書き出しができます。
- アプリが途中で落ちても、そこまでの録音と文字起こしは残ります。

## 仕組み

```
マイク（自分の声）と相手の音（WASAPI）を別々に録る
  |
  v
発話ごとに区切り、Whisper（PCの中）で文字起こしする
  |  結果はJSONLに追記する
  v
約45秒ごとに、文字起こしと発表資料（PPTX）のテキストを
LLMのサーバー（OpenAI互換API）に送って要約する
  |
  v
録音を止めたら、全体の最終要約を作る
```

| 要素 | 使ったもの |
|---|---|
| 画面 | WPF（.NET 10） |
| 録音 | NAudio（WASAPI、アプリごとの音の取得） |
| 文字起こし | Whisper.net（`small-q5_0` モデル） |
| 資料の読み取り | DocumentFormat.OpenXml |
| 要約 | OpenAI互換API（`/v1/chat/completions`） |

LLMのサーバーへ送るのは、確定した文字起こし、PPTXから取り出したテキスト、直前の要約だけです。音声と録音ファイルは送りません。APIキーはWindowsの資格情報マネージャーに保存します。録音の設定の注意、保存先の構成、今の制約は [docs/details.md](docs/details.md) にまとめています。

## 作っていて分かったこと

- Whisperは、同じ読みの別の字（火葬場を「仮想場」など）と固有名詞に弱く、音楽や広告の部分では実際には言っていない文（「ご視聴ありがとうございました」など）を作ることがありました。一方で、ニュース番組で試したときは、要約の段階でLLMがその誤りを直していました（「仮想場」を「火葬場」に戻すなど）。
- 「自分」と「相手」は声ではなく、録った経路で分けています。オンラインのゼミなら正しく分かれますが、相手が何人いても全員「相手」になります。
- 録音を止めた後の最終要約は、LLMに考えさせるモードだと長い録音で時間切れになりました。300秒で終わらなければ、考えさせないモードで取り直すようにしています。
- 録音の保存では、WindowsのFLACエンコーダーが44.1kHz以上しか受け付けず、16kHzの録音のままでは変換に失敗していました。48kHzに上げてから変換するように直しました。

## 動かし方

.NET 10 SDK が必要です。PowerShellでこのフォルダを開き、次を実行します。

```powershell
.\run.ps1
```

初めて録音するときに、Whisperのモデルをダウンロードします。要約を使う場合は、画面上部の「Qwenの接続設定」で、サーバーのBase URL（例: `http://server:8000/v1/`）とモデル名を入れます。サーバーが無い、または止まっていても、録音と文字起こしは続きます。

ビルドとテスト、配布用の実行ファイルの作成は次のとおりです。

```powershell
.\build.ps1
.\publish.ps1
```

`publish.ps1` は、.NETを入れていないPCでも動く実行ファイルを `artifacts\publish\win-x64\ZemiLog.App.exe` に作ります。

## ファイル構成

| 場所 | 内容 |
|---|---|
| `src/ZemiLog.Core/` | 記録の保存、PPTXの読み取り、要約の依頼、Markdownの書き出し |
| `src/ZemiLog.App/` | 録音、文字起こし、画面 |
| `tests/ZemiLog.Tests/` | `ZemiLog.Core` のテスト |
| `docs/details.md` | 保存先の構成、録音の設定の注意、今の制約 |

## 注意

個人で使うために作ったアプリです。相手の音を録るときは、録音することを参加者に伝えてから使ってください。

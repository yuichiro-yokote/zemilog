# ゼミログ

Windows 11上で、マイクと選択した会議アプリの音声を別々に録音し、日本語で文字起こししながら研究フィードバックを整理する個人用アプリです。

## 現在できること

- マイクと相手の音を別トラックで録音。相手の音は既定で「PC全体の音（既定のスピーカー出力）」で、アプリを選ばずにPCで流れている音をまるごと録る。Zoom・Teams・ブラウザなど、特定のアプリの音だけを選ぶこともできる
- マイク欄は前回録音したときの選択を覚える。初めて使うときは、Windowsの通話用の既定マイクが選ばれる。ステレオミキサーのような「スピーカー出力を録る入力」は一覧の最後にある
- 動画の要約など自分が話さないときは、マイク欄を「使わない（相手の音だけ録る）」にする。マイク欄をステレオミキサーにして相手の音を「PC全体の音」にすると、同じ音が「自分」と「相手」に二重に入る
- Whisper `small-q5_0`によるローカル日本語文字起こし（音声は外部送信しない）
- 入力経路に基づく「自分」「相手」の話者表示
- 約45秒ごとのQwen（ローカルのOpenAI互換サーバー）によるローリング要約と、停止後の最終要約。最終要約は思考ありで作り、300秒で終わらなければ思考なしで取り直す（そのときは「最終版（思考なし）」と表示）
- PPTXのスライド本文・番号・発表者ノートを要約の文脈として利用
- セッション履歴、マイク＋相手音声の混合再生、Markdown出力
- 異常終了時のWAV保持と、追記型JSONLによる文字起こし保護

## 起動

PowerShellでこのフォルダを開き、次を実行します。

```powershell
.\run.ps1
```

初回録音時だけWhisperモデルをダウンロードします。モデルは`%LOCALAPPDATA%\ZemiLog\models`へ保存されます。

## Qwen設定

アプリ上部の「Qwenの接続設定」を開き、OpenAI互換サーバーのBase URLとモデル名を入力します。

- Base URL例: `http://server:8000/v1/`
- 利用API: `GET /v1/models`、`POST /v1/chat/completions`
- APIキーはWindows資格情報マネージャーへ保存
- サーバーへ送るもの: 確定文字起こし、PPTXから抽出したテキスト、直前の要約
- サーバーへ送らないもの: マイク音声、会議アプリ音声、録音ファイル

Qwenが未設定・停止中でも録音と文字起こしは続きます。要約欄には保留状態が表示されます。

## 保存先

セッションは`%LOCALAPPDATA%\ZemiLog\sessions`に保存します。

```text
<日時-ID>/
  session.json
  deck.json
  transcript.jsonl
  summaries.jsonl
  mic.flac または mic.recording.wav
  remote.flac または remote.recording.wav
  presentation.pptx（選択した場合）
  pending/（未処理の発話WAV）
```

録音中は復旧可能なWAVを使用し、正常停止後にFLACへ変換します。WindowsのFLACエンコーダーは44.1kHz以上しか受け付けないため、FLACは16kHzの録音を48kHzへリサンプルして保存します（文字起こしに使う16kHzの処理は変わりません）。音が1サンプルも無い側のWAVはFLACを作らずに削除します。FLAC変換に失敗した場合はWAVを削除せず、停止後にエラーを表示します。

## 開発・確認

```powershell
.\build.ps1
```

構成は、保存・PPTX・要約・Markdownを`ZemiLog.Core`、WASAPI・Whisper・WPF UIを`ZemiLog.App`へ分離しています。

別PCでも.NETの事前導入なしで動く自己完結版は次で作成します。

```powershell
.\publish.ps1
```

成果物は`artifacts\publish\win-x64\ZemiLog.App.exe`です。

## 初版の制約

- 相手を個人別には識別しません。
- スピーカー使用時の二重取りは類似文章で抑制しますが、完全には除去できません。
- PPTX内の画像・グラフ自体は解釈しません。
- CPU性能より文字起こしが遅い場合も、自動的に`base`モデルへ落とさず、未処理件数を表示します。
- 特定のアプリを選んだ場合、そのアプリが終了しても、PC全体の音声取得へは自動変更しません。
- 「PC全体の音」は、録音開始時の既定のスピーカー出力を録ります。録音中に出力先（イヤホン・スピーカーなど）を切り替えると追従しません。通知音など、会議以外の音も入ります。

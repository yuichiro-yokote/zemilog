# 詳細

READMEに載せきれない、保存先・録音の設定・制約の説明です。

## 録音の設定

- 相手の音は、既定では「PC全体の音（既定のスピーカー出力）」です。アプリを選ばずに、PCで流れている音をまとめて録ります。Zoom・Teams・ブラウザなど、特定のアプリの音だけを選ぶこともできます。
- マイク欄は、前回録音したときの選択を覚えます。初めて使うときは、Windowsの通話用の既定マイクが選ばれます。ステレオミキサーのような「スピーカー出力を録る入力」は一覧の最後にあります。
- 動画の要約など自分が話さないときは、マイク欄を「使わない（相手の音だけ録る）」にします。マイク欄をステレオミキサーにして相手の音を「PC全体の音」にすると、同じ音が「自分」と「相手」に二重に入ります。

## 要約

- 約45秒ごとに、そこまでの文字起こしから要約を作り直します。
- 録音を止めた後の最終要約は、思考ありのモードで作ります。300秒で終わらなければ思考なしで取り直し、その場合は「最終版（思考なし）」と表示します。
- 利用するAPIは `GET /v1/models` と `POST /v1/chat/completions` です。

## 保存先

Whisperのモデルは `%LOCALAPPDATA%\ZemiLog\models`、記録は `%LOCALAPPDATA%\ZemiLog\sessions` に保存します。

```text
<日時-ID>/
  session.json
  deck.json
  transcript.jsonl
  summaries.jsonl
  mic.flac または mic.recording.wav
  remote.flac または remote.recording.wav
  presentation.pptx（選んだ場合）
  pending/（まだ文字起こししていない発話のWAV）
```

録音中は、途中で落ちても読めるWAVで保存し、正常に止めた後でFLACに変換します。WindowsのFLACエンコーダーは44.1kHz以上しか受け付けないため、16kHzの録音を48kHzに上げてから保存します（文字起こしに使う16kHzの処理は変わりません）。音が1サンプルも無い側のWAVは、FLACを作らずに消します。FLACへの変換に失敗した場合はWAVを消さず、止めた後でエラーを表示します。

## 今の制約

- 相手を一人ずつは見分けません。
- スピーカーで聞いているときの二重取りは、似た文を除くことで抑えていますが、完全には消せません。
- PPTXの中の画像やグラフは読み取りません。
- PCの性能より文字起こしが遅れても、自動で小さいモデル（`base`）には切り替えず、未処理の件数を表示します。
- 特定のアプリを選んだ場合、そのアプリが終了しても、PC全体の音には自動で切り替えません。
- 「PC全体の音」は、録音を始めたときの既定のスピーカー出力を録ります。録音中に出力先（イヤホン・スピーカーなど）を切り替えても追従しません。通知音など、会議以外の音も入ります。
